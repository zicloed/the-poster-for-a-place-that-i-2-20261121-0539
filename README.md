A make.fun bounty entry: a vintage travel poster for Kestrel, a place that does not exist — a low sun over a still lake, three mountain ridges, pine silhouettes, and the promise that the sky keeps. The same imaginary country as the "Passport of Kestrel" entry, so the two form one world.

## Run it

```sh
python3 main.py
```

It writes one 1024x1024 PNG to `/output/entry.png`, deterministically — the same bytes on every run. Pillow only, no network, no clock.
